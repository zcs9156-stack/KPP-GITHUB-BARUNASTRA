# GitHub Learning Repository

Repository ini merupakan dokumentasi pembelajaran mandiri tentang Git, GitHub, Markdown, dan penerapannya dalam pengembangan proyek teknologi.

Tujuan repository ini adalah membangun pemahaman mengenai version control, kolaborasi pengembangan perangkat lunak, pengelolaan dokumentasi, serta riset teknologi secara terstruktur.

## Tujuan Pembelajaran

- Memahami konsep dasar Git dan GitHub.
- Mempelajari penggunaan Markdown untuk dokumentasi.
- Memahami workflow commit, branch, merge, dan push.
- Menerapkan GitHub dalam kegiatan belajar dan pengembangan proyek.
- Melakukan riset mandiri menggunakan repository dan dokumentasi teknologi.

## Workflow Git Dasar

Workflow yang digunakan dalam pembelajaran ini meliputi:

1. `git status` — memeriksa perubahan.
2. `git add` — menyiapkan perubahan untuk commit.
3. `git commit` — menyimpan perubahan ke riwayat Git.
4. `git switch -c nama-branch` — membuat dan berpindah ke branch baru.
5. `git merge nama-branch` — menggabungkan perubahan branch.
6. `git push` — mengirim commit ke repository remote.

## Cara Menggunakan Repository

1. Buka materi yang ingin dipelajari dari bagian **Daftar Materi**.
2. Pelajari konsep dan contoh yang tersedia.
3. Praktikkan perintah Git pada repository lokal.
4. Catat hasil eksperimen dan temuan baru.
5. Perbarui dokumentasi secara bertahap menggunakan commit yang jelas.
